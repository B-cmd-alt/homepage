Memory System Evaluator

Ten agent-memory systems, one model, one embedder, one calibrated judge. Every number traces to the case that produced it.

Try it live → Evidence page Full write-up and code on GitHub
66cells in round 2: 11 systems × 3 seeded worlds × 2 generator tiers
0.95–1.00recall: full context (2023) ties GraphRAG, Mem0 and Mastra
×39write cost, cheapest to most expensive system that makes model calls
9defects in my own benchmark, caught and fixed before any number was reported

The question. Memory vendors report benchmark scores in the nineties; independent re-runs land in the thirties and forties. Before comparing memory systems, I had to build an evaluation I could trust.

What it shows so far. On recall, simply putting everything in context is not beaten. The systems separate on updates: vector RAG and BM25 still serve the superseded value about a third of the time, a reranker fixes it, and the temporal knowledge graph does worse than the 2023 baselines.

The live app has three tabs: Be the Judge, Ask the Memory and Break the Memory. The benchmark design, the judge calibration and both rounds are written up in the GitHub README.

PipelineAgent

A detection-and-repair agent for data pipelines that watches the data, not the job.

Open the live dashboard → Full write-up and code on GitHub
7public feeds, hourly, append-only with vintages
3detector axes that read data, never exit codes
< $2per month, steady state, on Cloud Run
hour 1first real breach: FRED began timing out from the cloud

The question. The pipeline failure that hurt me most in production was never a crash. It was a job that exited 0 every morning while writing nothing, for weeks, under monitoring that only watched exit codes.

What it shows so far. Real sources break in ways synthetic ones don't: a government feed that answers once and then resets connections, a market API that rate-limits, a grid operator whose hour column stays on standard time all year. When a detector cannot look, it says UNKNOWN, shown amber and never green.

The dashboard is re-rendered by the hourly job itself. It turns amber, then red, if the loop stops.

Both projects run on one rule: the thing being evaluated never grades itself.
